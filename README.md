# CodeAndConquer – DSA Practice Repository

This repository contains my learning and practice of
Data Structures and Algorithms using C++.

I created this repository to organize the concepts, algorithms,
and problems I learned throughout my DSA journey.

The repository includes implementations, practice problems,
and solutions covering fundamental to advanced DSA topics.

## Repository Structure

- Each topic has its own folder.
- Problems inside a topic are ordered numerically.
- Each solution is written in *C++*.
- Topic-wise README.md files explain the problems covered.

## Practice Approach

- Solve problems daily (mainly from LeetCode).
- Focus on understanding logic and patterns.
- Maintain clean, readable, and well-named files.
- Gradually move from Easy to Medium and Hard problems.
